# Flashcard Quiz App

A small Python project I made to practice working with dictionaries, loops, functions, and user input. The app ask random questions from a set of flashcards and keeps track of your score.

It is simple, but it was a fun way to combine basic Python concepts into one project.

## Features

* Randomized flashcard questions
* Instant feedback after every answer
* Final score and percentage calculation
* Easy to add your own questions

## How It Works

The program stores flashcards as question-answer pairs in a Python dictionary. When you start the quiz, the questions are shuffled and displayed one by one. At the end, your total score and percentage are shown.

## Running the Project

Clone the repository:

```bash
git clone https://github.com/your-username/Flashcard-Quiz-App.git
```

Move into the project folder:

```bash
cd Flashcard-Quiz-App
```

Run the file:

```bash
python flashcard_quiz.py
```
